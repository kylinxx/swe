# 最终提交清单

## 必须确认

- `README.txt` 已写入公开仓库地址。
- `README.txt` 内容控制在 1000 汉字以内。
- 仓库保留完整提交历史，没有压缩或改写历史。
- 仓库里没有任何 `API key`、`.env` 内容或其他敏感信息。
- 本地测试通过：`python -m unittest discover -s tests`。

## 视频要求

- 时长不超过 2 分钟。
- 格式为 `mp4`。
- 文件大小不超过 200 MB。
- 视频内容包含：
  - 项目简介
  - 运行演示
  - agent 自动修复过程
  - 运行报告展示

## 打包要求

- 只提交一个以你姓名命名的 `zip` 文件。
- `zip` 内只放 `README.txt` 和视频文件。
- 最终以平台最后一次提交为准。

## 推荐顺序

1. 先确认 GitHub 仓库公开可访问。
2. 再确认 `README.txt` 最终版无误。
3. 录制并检查视频时长和大小。
4. 最后打包成 `你的姓名.zip`。
