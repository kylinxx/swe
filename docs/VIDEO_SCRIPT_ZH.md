# 视频 Demo 脚本（2 分钟版）

## 开场（0:00 - 0:15）

“大家好，我做的是一个从零实现的编程智能体。它可以和大模型交互，自动读写本地文件、执行命令，并在完成任务后生成运行报告。”

## 项目亮点（0:15 - 0:35）

“这个项目没有套用现成 agent 框架，核心逻辑都是我自己写的。整体分成四层：LLM 客户端、本地工具层、上下文管理器、以及主循环控制器。”

“另外我加了计划模式，能先生成结构化计划，再一步步执行，更适合展示复杂任务。”

## 演示任务（0:35 - 1:20）

“我这里用一个小型 bug 项目来演示。它的测试是故意失败的，我让 agent 先分析问题，再自动修复。”

运行命令：

```bash
python -m coding_agent --cwd demo_workspace/mini_buggy_app --plan "请修复测试失败并说明原因"
```

“可以看到它先生成计划，然后读取文件、搜索代码、修改代码，最后重新跑测试。”

## 结果展示（1:20 - 1:45）

“修复完成后，测试通过。与此同时，系统会自动保存一份运行报告，里面有计划、工具调用轨迹、事件日志和最终结果。”

打开目录：

```bash
.coding-agent/runs/
```

## 收尾总结（1:45 - 2:00）

“这个项目的重点不是简单调用模型接口，而是把 agent 的完整闭环自己实现出来：理解任务、制定计划、调用工具、验证结果、保存证据。它是一个简化版但完整的本地 coding agent。”

## 录制建议

- 全程不要展示 `.env` 和 API key。
- 如果终端输出太长，可以适当加速。
- 建议固定使用 `demo_workspace/mini_buggy_app`，这样更稳、更容易复现。
- 最后一定要展示运行报告，评委会更容易看出你的工程化能力。
