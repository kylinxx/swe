Git 仓库地址：请填写公开仓库链接。

运行方式：
1. 设置环境变量 `OPENAI_API_KEY`，按需再设 `OPENAI_BASE_URL`、`OPENAI_MODEL`。
2. 在仓库根目录运行：`python -m coding_agent "你的编程任务"`。
3. 加上 `--plan` 可先生成执行计划，再进入工具执行循环。
4. 可用 `--cwd` 指定工作区目录，智能体只允许在该目录内读写文件和执行命令。
5. 每次成功运行会自动保存报告到 `.coding-agent/runs/`。

特色功能：
- 从零实现 LLM 调用、上下文管理、本地工具执行和主事件循环，不依赖现成 agent 框架。
- 支持读写文件、目录浏览、全文搜索、精确替换和命令执行。
- 带有工作区边界检查、命令超时、输出截断、错误回传和上下文裁剪。
- 支持计划模式：先产出结构化 plan，再按 plan 逐步执行，更适合复杂任务演示。
- 自动保存运行报告，便于复盘、答辩和展示调试过程。

演示建议：
- 直接使用 `demo_workspace/mini_buggy_app` 录视频：先让 agent 跑测试，再修复 `average()` 的错误，最后重跑测试。
